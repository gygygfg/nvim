# 🚀 MCP 服务器工具组使用指南

## 📋 概述
`mcp_servers` 是 CodeCompanion 的智能 MCP 服务器工具组，能够自动分析用户需求并选择最合适的 MCP 服务器工具。

## 🎯 核心功能

### 🔍 智能需求分析
- 自动识别用户输入中的技术关键词
- 判断任务类型和所属技术领域
- 计算匹配置信度

### 🤖 自动工具选择
- 根据关键词匹配最合适的 MCP 工具
- 按优先级排序推荐工具
- 当置信度足够高时自动执行

### 📊 透明化展示
- 显示工具选择过程
- 解释推荐理由
- 展示所有可用工具

## 💡 使用方式

### 方法 1: 直接描述需求（推荐）
```bash
# 在 CodeCompanion 聊天窗口中输入
我想了解 React 的 useState hook
```
**系统会自动：**
1. 分析关键词：`React`、`useState`、`hook`、`了解`
2. 识别任务类型：文档查询
3. 选择工具：`@{context7}`
4. 获取并返回 React useState Hook 文档

### 方法 2: 使用 @{mcp_servers} 工具组
```bash
# 明确使用工具组
@{mcp_servers} 如何爬取一个网页的内容
```
**系统会：**
1. 显示所有可用 MCP 工具
2. 推荐最合适的工具：`@{crawl4ai}`
3. 提供使用建议

### 方法 3: 查看可用工具
```bash
# 查看所有 MCP 工具
@{mcp_servers}
```
**系统会显示：**
- 所有可用的 MCP 工具列表
- 每个工具的描述和用途
- 使用示例

## 🔧 配置优化详情

### 1. 优先级设置
- `mcp_servers`: 优先级 -1（最高）
- 在默认工具列表中排第一位
- 自动触发阈值：0.3

### 2. 关键词扩展
新增了大量技术关键词，覆盖：
- 文档查询相关（文档、教程、指南、示例）
- 网页内容相关（爬取、抓取、网页、网站）
- 技术查询相关（如何、怎么、什么是、解释）
- 编辑器操作相关（Neovim、配置、设置、快捷键）
- GitHub 操作相关（仓库、代码库、拉取请求）
- 文件系统相关（文件、目录、路径、创建、删除）
- 编程开发相关（代码、编程、调试、测试）

### 3. 智能选择规则
详细的优先级规则，包括：
- **文档查询**（优先级 10）：`context7`
- **文档搜索**（优先级 9）：`context7_search`
- **网页爬取**（优先级 8）：`crawl4ai`
- **编辑器操作**（优先级 6）：`neovim`
- **GitHub 操作**（优先级 5）：`github`
- **文件系统操作**（优先级 4）：`filesystem`

## 🔍 故障排除

### 问题 1: mcp_servers 没有自动触发
**可能原因：**
- 输入中没有匹配的关键词
- 置信度低于阈值（0.3）

**解决方案：**
```bash
# 明确使用工具组
@{mcp_servers} 你的需求描述
```

### 问题 2: 选择了错误的工具
**可能原因：**
- 关键词匹配不准确
- 优先级规则需要调整

**解决方案：**
```bash
# 直接使用特定工具
@{context7} 查询具体内容
@{crawl4ai} 爬取特定网页
```

### 问题 3: MCP 服务器不可用
**可能原因：**
- MCP 服务器未正确配置
- 服务器进程未启动

**解决方案：**
1. 检查 MCP 服务器配置
2. 重启 Neovim
3. 运行 `:MCPStatus` 检查状态
